# Surprise Horse / 高配当警戒度 研究まとめ — 2026-08-29

## 1. 今日の目的

通常の中央PCKEIBA AIでは、AI1軸・AI2〜AI5中心の予想は一定の的中力を持つ一方、順位をAI10まで広げても安定したROI100%超にはつながらなかった。

そこで今日は、次の2方向を調査した。

1. 通常4点に「派手な穴2点」を追加できる Surprise Horse の可能性
2. そもそも馬連万馬券が発生しやすいレース構造を判定する「高配当警戒度」の可能性

最終的には、穴馬2頭の個別選定よりも、レース単位で高配当化しやすい構造を示す方が再現性・実用性ともに高いという結論になった。

---

# 2. Surprise Horse Phase S0〜S2

## S0: 穴紐実態調査

対象条件:

- baseline_v0_1
- BASE4点（AI1-AI2〜AI5）が不的中
- AI1は2着以内
- 実際の馬連相手がAI6以下

対象件数:

- 2024: 456R
- 2025: 515R

主な特徴:

- AI6〜7位が最多
  - 2024: 46.3%
  - 2025: 43.3%
- AI9位までで約7割
- 人気は4〜6番人気が最多
- 馬連払戻中央値
  - 2024: 2,110円
  - 2025: 2,160円
- 穴紐は同レースAI6+非好走馬よりAI5 scoreに近い
- 両年共通で、近走成績・4角位置・CK先行率などに同方向の差

判定:

**一部特徴のみ継続調査**

## S1: 特徴絞り込み

2024のみを開発年として5特徴を固定。

1. AI順位
2. AI5 scoreとの差
3. 近3走平均着順
4. 近3走4角位置率
5. CK先行率

単変量AUC（2024）:

- AI順位: 0.716
- AI5差: 0.675
- 近3走平均着順: 0.621
- 4角: 0.598
- CK: 0.586

2025は未調整確認のみ。

固定5特徴はすべて2025でも同方向に再現。
等重みpercentile参考score AUC:

- 2024: 0.705
- 2025: 0.694

判定:

**S2へ進む**

## S2: 候補2頭ranking診断

固定5特徴ranking Top2捕捉率:

- 2024: 44.08%
- 2025: 41.36%

しかしAI順位だけでAI6・AI7を選ぶ基準より、

- 2024: -2.19pt
- 2025: -1.94pt

と両年とも低下。

さらに、

- AI10以下捕捉率: 7.26% / 4.27%
- 10番人気以上捕捉率: 15.38% / 9.64%

で、派手な穴を安定して2頭へ絞る選別力は確認できなかった。

最終判定:

**構造弱く終了**

重要な結論:

> 穴紐馬には記述可能な共通傾向はあるが、その情報だけではAI順位上位の単純選択を上回る2頭選定ロジックにはならない。

# 3. 馬連万馬券 発生構造 Phase M0〜M2

## M0: 万馬券の生構造

馬連100円払戻10,000円以上を万馬券と定義。

2011〜2025の年間発生数:

- 363〜474組
- 発生率 約10.9〜14.3%

直近:

- 2024: 11.06%
- 2025: 12.20%

生人気組合せ最多:

**3人気-11人気（152組）**

ただし4〜9人気同士も1,592組あり、単純な「本命+大穴」だけではない。

人気順位:

- 順位差中央値: 6
- 順位合計中央値: 15

頭数別万馬券率例:

- 12頭: 9.34%
- 16頭: 15.63%
- 17頭: 18.90%

AI1関与:

- 2024: 10.08%
- 2025: 10.65%

1番人気関与:

- 2024: 8.75%
- 2025: 9.93%

約9割の万馬券ではAI1・1番人気とも連対していない。

5万円以上では人気順位合計中央値19、1番人気関与1.61%。
10万円以上では人気順位合計中央値22、1番人気関与0%。

## M1: AI対人気乖離

万馬券で「人気順位よりAI順位が良い馬」が少なくとも1頭いる割合:

- 2024: 63.86%
- 2025: 65.11%

非万馬券:

- 2024: 44.88%
- 2025: 45.25%

正gapは1頭だけの型が最多:

- 2024: 47.83%
- 2025: 49.39%

ただし多頭数ほどgapそのものが拡大するわけではない。

## M2: 16頭以上固定・交絡診断

16頭以上の生値では正gap馬あり率が万馬券側で高い。

- 2024: 60.73% vs 44.64%
- 2025: 68.20% vs 44.21%

しかし人気順位合計を揃えると、十分な母数のある12〜15帯で逆転。

- 2024: 51.28% vs 78.67%
- 2025: 55.91% vs 77.78%

最終判定:

**一部のみ残る**

重要な結論:

> 「市場よりAI順位が良い馬を含む万馬券」という現象の一部は、人気・AI順位の組合せ構造の副産物。

この乖離現象だけを理由にwalk-forward baselineを過去年へ拡張する必要はない。

# 4. レース単位の万馬券構造 Phase M3

個別馬ではなく、発走前に分かるレース単位の構造を診断。

2024/2025で同方向だった特徴:

- 出走頭数が多い
- 1番人気単勝オッズが高い
- 市場支持が分散
  - エントロピー高
  - Top3/Top5支持集中度低
- AI1 scoreが低い
- AI1-AI2 / AI1-AI5 gapが小さい
- Top3 score合計が低い
- AI score標準偏差が低い
- 市場Top3/Top5とAI Top3/Top5の重なりが少ない

つまり、

> 多頭数 + 1番人気が弱い + 市場支持分散 + AI上位拮抗 + 市場とAIの見解不一致

のレースで万馬券が増える方向。

判定:

**一部構造あり**

# 6. Phase M5: 高配当警戒度の5段階化

M4 Model 4と境界は固定。

- LOW
- NORMAL
- WATCH
- HIGH
- EXTREME

- 2025: 9.74%

- 2024: 15件

判定:

**M6へ進む**

# 7. Phase M6: UI仕様

最終名称:

**高配当警戒度**

推奨表示:

```text
高配当警戒度  〰  HIGH
高配当化しやすい構造に注意
```

推奨位置:

**Compass直下の独立行**

役割分離:

- Compass = 市場構造・レース参加判断
- AI順位 = 馬の相対評価
- 高配当警戒度 = レース全体が高配当化しやすい構造か

重要:

- 馬券購入推奨ではない
- 万馬券予告ではない
- HIGH/EXTREMEでも高配当を保証しない
- LOWでも万馬券は発生する
- 内部scoreは常時表示しない
- 過去発生率も常時表示しない
- Web先行で文言・ヘルプ・スマホ収まりを確認後、アプリ展開

M6最終判定:

**M7実装設計へ進む**

---

# 8. 今日の最終結論

Surprise Horseは、穴馬の特徴自体は見えたが、2頭へ選別する段階でAI6・AI7固定を超えず終了した。

一方、万馬券研究では「どの穴馬が来るか」ではなく、

**高配当が発生しやすいレース全体の構造**

に再現性が確認できた。

したがって今後は、予想の的中馬を増やす方向ではなく、

> **高配当警戒度 = ユーザーの判断材料を増やす道具**

として扱う。

これは「道具屋に徹する」という研究方針とも整合する。

次回は **Phase M7: 実装設計** から再開する。
