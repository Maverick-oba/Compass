# 高配当警戒度 ヘルプ文案 v0.1

## 短文

**高配当警戒度**は、そのレースが高配当化しやすい構造かを5段階で示す補助指標です。

馬や買い目を予想するものではなく、HIGH・EXTREMEでも高配当を保証しません。LOWでも高配当は発生します。

## 標準文

### 高配当警戒度とは？

高配当警戒度は、過去の中央競馬データをもとに、レース全体が高配当化しやすい構造かを相対的に示す指標です。

表示は次の5段階です。

- LOW
- NORMAL
- WATCH
- HIGH
- EXTREME

HIGHやEXTREMEほど、過去検証では馬連万馬券が発生する割合が高い傾向が確認されています。

ただし、この指標は「万馬券が出る」という予告ではありません。また、どの馬が来るか、どの馬券を買うべきかを示すものでもありません。

LOWでも万馬券は発生します。HIGHやEXTREMEでも高配当にならないレースは多数あります。

レース選びや予想を考える際の、ひとつの判断材料として利用してください。

## 過去検証例

固定モデルによる2024・2025年の検証では、馬連万馬券率はLOWからEXTREMEへ段階的に上昇しました。

- LOW: 2024年 4.95% / 2025年 3.95%
- EXTREME: 2024年 17.27% / 2025年 19.89%

これは過去データで確認された傾向であり、将来の結果を保証するものではありません。

## UI向け最短説明

`レース全体の高配当化しやすさを示す相対指標です。馬券や馬を予測するものではありません。`

## 段階別補助文案

- LOW: `高配当警戒は低め`
- NORMAL: `標準的な高配当警戒度`
- WATCH: `やや高配当に注意`
- HIGH: `高配当化しやすい構造に注意`
- EXTREME: `高配当警戒が強いレース構造`

## 使用しない表現

- 万馬券濃厚
- 高配当確定
- 激アツ
- 買い推奨
- 万馬券期待大
- 安全
- 堅い
- 荒れない

高配当警戒度は、購入推奨や結果保証ではなく、レース構造を示す補助情報として扱う。
