# 高配当警戒度 UI仕様 v0.1

## 1. 目的

中央PCKEIBA研究 Phase M4〜M6で固定した「高配当警戒度」を、既存CompassやAI順位とは別の補助情報としてユーザーへ表示する。

本指標は、馬券や馬を予測するものではない。

目的は、

**そのレースが高配当化しやすい構造かを相対的に示すこと。**

## 2. 指標名

表示名:

**高配当警戒度**

内部version案:

`high_payout_alert_v0_1`

## 3. 5段階

- LOW
- NORMAL
- WATCH
- HIGH
- EXTREME

M4/M5で固定した境界をそのまま使用する。

再学習・係数変更・閾値変更をUI都合で行わない。

## 4. 過去検証実績

LOWの馬連万馬券率:

- 2024: 4.95%
- 2025: 3.95%

EXTREMEの馬連万馬券率:

- 2024: 17.27%
- 2025: 19.89%

EXTREMEの2万円以上率:

- 2024: 8.56%
- 2025: 9.74%

EXTREMEの5万円以上件数:

- 2024: 15件
- 2025: 22件

HIGH + EXTREMEの全体比lift:

- 2024: 1.46倍
- 2025: 1.45倍

上記は過去データでの相対的傾向であり、未来の高配当を保証する数値ではない。

## 5. 役割分離

### Compass

市場構造・レース参加判断の補助。

### AI順位

各馬の相対評価・中心候補。

### 高配当警戒度

レース全体が高配当化しやすい構造かを示す補助指標。

3つを混同しない。

## 6. 推奨表示位置

**Compass表示の直下に独立した1行として表示する。**

推奨例:

```text
高配当警戒度  〰  HIGH
高配当化しやすい構造に注意
```

理由:

- Compassと関連情報として近くに置ける
- AI順位とは視覚的に分離できる
- 独立カードよりスマホ縦方向を圧迫しにくい
- レースカード内で意味を理解しやすい

## 7. 段階別短文案

### LOW

`高配当警戒は低め`

### NORMAL

`標準的な高配当警戒度`

### WATCH

`やや高配当に注意`

### HIGH

`高配当化しやすい構造に注意`

### EXTREME

`高配当警戒が強いレース構造`

断定・購入誘導表現は使用しない。

禁止例:

- 万馬券濃厚
- 激アツ
- 買い
- 高配当確定
- 万馬券期待大

## 8. EXTREMEの扱い

EXTREMEは最も目立たせてよいが、警告・予告のような断定表示にはしない。

EXTREMEでも2024/2025の万馬券率は約17〜20%。

したがって、視覚的強調は「相対的に警戒が強い」範囲に留める。

## 9. LOWの扱い

LOWでも万馬券は発生する。

以下の表現は禁止する。

- 安全
- 堅い
- 荒れない
- 万馬券なし

LOWはあくまで、

**相対的に高配当警戒が低い。**

## 10. 色・視覚設計

5段階で視覚差を設けるが、色だけに依存しない。

併用するもの:

- 段階名
- テキスト
- アイコン
- ラベル

既存Compassの配色と競合しないこと。

色覚差にも配慮する。

## 11. アイコン

推奨方向:

**波形 / 変動を示すシンプルなアイコン。**

例:

`〰`

炎・爆発などギャンブル煽りが強いアイコンは基本採用しない。

## 12. score・過去率表示

### 内部score

常時表示しない。

理由:

Model 4のscoreは、そのまま将来の万馬券確率を保証するものではない。

### 過去発生率

レースカード上では常時表示しない。

ヘルプ画面等で、過去検証例として提示することは可能。

## 13. 必須注意事項

ユーザー向け説明には、次の意味を含める。

- レース全体の高配当傾向を示す補助指標
- 馬券や馬を予測するものではない
- HIGH/EXTREMEでも高配当を保証しない
- LOWでも高配当は発生する
- 過去データを基にした相対評価

## 14. 実装順

推奨:

1. Webで先行表示
2. 文言確認
3. ヘルプ導線確認
4. スマホ画面での収まり確認
5. 問題なければアプリへ展開

## 15. JSON案

実装候補:

```json
{
  "high_payout_alert_level": "HIGH",
  "high_payout_alert_score": 0.0,
  "high_payout_alert_version": "high_payout_alert_v0_1"
}
```

`high_payout_alert_score` は内部利用を想定し、UIへ常時表示しない。

既存JSON変更はM7以降の実装設計で決定する。
