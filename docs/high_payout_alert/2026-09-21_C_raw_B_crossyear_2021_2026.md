# 2021-2026 C raw / B gate cross-year comparison

## Important scope note

The uploaded 2026 comparison file is named `race_level_2026_through_20260920.csv`, but its actual maximum `race_date` is 2026-09-13 and it contains 2,406 races.
Therefore every 2026 figure in this note is **through 2026-09-13**, not Sep 20.

No thresholds were retuned.

Definitions:
- B gate: field_size in (13,14) AND ai_top3_sum < 1.30
- C raw: field_size in (15,16) AND ai_score_std <= 0.135

| 2026* | 493 | 75 | 15.21% | 10.28% | +4.93 | 1.48x |

*2026 through Sep 13.

Fisher exact tests for C raw vs same-field-size non-C:
- 2021 p=0.000827
- 2022 p=0.00436
- 2023 p=6.46e-08
- 2024 p=0.0216
- 2025 p=0.00112
- 2026* p=0.0189

Pooled six-period result:
- C raw: 736 / 4,121 = 17.86%
- non-C: 471 / 4,100 = 11.49%
- odds ratio about 1.68
- Fisher p about 3.3e-16

A logistic year-interaction model did not show a clear change in the C-raw effect by year. Relative to 2021, all gate x year interaction p-values were >0.12.

This is evidence of repeated separation, but it is not a production-rule conclusion.

## C raw vs formal C: A-overlap effect

Because B uses 13-14 runners and C raw uses 15-16 runners, B cannot overlap C raw.
Therefore, for years where formal C is defined as C raw after A/B exclusion, the difference between raw C and formal C is effectively the A-overlap subset.

2024:
- C raw: 679 races / 114 x 100x = 16.79%
- formal C: 242 / 44 = 18.18%
- inferred raw-C ∩ A: 437 / 70 = 16.02%

2025:
- C raw: 758 / 146 = 19.26%
- formal C: 252 / 44 = 17.46%
- inferred raw-C ∩ A: 506 / 102 = 20.16%

The direction flips:
- 2024 A exclusion slightly increases C rate.
- 2025 A exclusion decreases C rate.

Therefore formal-C year variation can be influenced materially by how C raw overlaps the frozen A route. Formal C and C raw should remain separate objects in future analysis.

2026 cannot be safely decomposed this way yet because the current raw file ends Sep 13 while the existing formal-C reference runs through Sep 20.

## Current anti-overinterpretation stance

What the six-period data currently supports:
- C raw is above same-field-size non-C in every observed year/period.
- Its absolute rate varies: roughly 15-20%, so it is not a fixed 20% phenomenon.
- B is less uniform and has at least one clear weak year (2022).
- Formal C should not be used as a proxy for raw C because A-overlap materially changes the observed rate and even the direction of that change differs by year.

What it does not yet support:
- calling C raw a finalized production type;
- treating B as an automatic mode switch;
- optimizing new C thresholds;
- optimizing fixed betting pairs from this comparison.

Next robustness work:
1. Correct/extend the 2026 raw file through the intended Sep 20 cutoff.
2. Compare C raw over calendar windows inside each year, rather than only annual totals.
3. Check whether relative lift versus same-field-size controls persists within broad surface/distance/grade strata, without creating new filters.
