## 単独指標の初期確認

### ai_gap12

Q1 -> Q4:
- AI1絡み: 39.6% -> 55.4%
- Top3完結: 24.3% -> 29.7%
- Top5完結: 48.5% -> 53.0%
- AI7以下含む: 39.6% -> 37.5%

解釈:
- AI1軸適性には関係しそう。
- ただしレース全体の決着範囲を強く狭める指標ではない。

### ai_gap15

Q1 -> Q4:
- AI1絡み: 35.6% -> 62.2%
- Top3完結: 18.2% -> 41.1%
- Top5完結: 42.1% -> 63.9%
- AI7以下含む: 47.0% -> 27.5%

解釈:
- 上位AI集中度と勝ち馬連の決着範囲の差が明瞭。
- 通常配当側の買い目型分け候補として有力。

### ai_score_std

Q1 -> Q4:
- AI1絡み: 38.2% -> 56.7%
- Top3完結: 17.9% -> 38.6%
- Top5完結: 39.8% -> 66.2%
- AI7以下含む: 50.7% -> 24.3%

頭数補正後も方向性は維持:
- Q1 Top3完結: 18.7%
- Q4 Top3完結: 36.0%
- Q1 AI7以下含む: 48.2%
- Q4 AI7以下含む: 28.7%

解釈:
- 単なる頭数効果ではなく、AI評価の集中/平坦さ自体に決着構造差がある。

各構造候補について、勝ち馬連AI順位ペアの詳細分布を比較する。

- AI1軸候補: 1-2,1-3,1-4,... の累積
- 上位拮抗候補: 1-2,1-3,2-3,1-4,2-4,3-4...

の確認。
