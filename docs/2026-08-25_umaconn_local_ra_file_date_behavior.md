# UmaConn 地方RAファイルの日付と開催日の不一致メモ

日付: 2026-08-25

## 目的

地方競馬のUmaConn / NVDTLabデータを直接扱う際、RAファイル名の日付と内部レースの開催日が一致しないケースを確認したため、今後の探索・スケジュール生成で再度誤判定しないよう記録する。

## 結論

地方RAでは、外側の `.nvd` ファイル名に含まれる日付を、そのまま内部レースの開催日とみなしてはいけない。

2026-08-25 船橋1R～12Rは、開催日名の `RANV20260825...nvd` ではなく、以下の8月22日付RAファイル内に先行収録されていた。

```text
C:\UmaConn\chiho.k-ba\data\cache\2026\RANV2026082220260822231018.nvd
```

内部RAレコードは2026-08-25・場コード43・1～12Rで、`data_sakusei_nengappi` は全件 `20260822` だった。

つまり、外側の `RANV20260822...` は内部レースの開催日ではなく、データ作成・配信側の日付を反映している。

## 確認内容

対象ファイル:

```text
RANV2026082220260822231018.nvd
```

確認結果:

- サイズ: 5,715 bytes

## 削除ではなかった

当初、PC-KEIBAで受信・DB取込後にRAファイルが削除された可能性を疑ったが、今回の対象RAファイルそのものがUmaConn本番cacheに現存していた。

したがって今回の不一致は、PC-KEIBAまたはUmaConnによる削除ではない。

確認範囲では:

- 正常取込後のRAを一律削除する処理は確認できない
- RAの別フォルダへの移動・退避も確認できない
- `NVFiledelete` 参照自体は存在するが、今回のRA消失原因ではない
- UmaConn/NVDTLabがNVRead後に `.nvd` を必ず自動削除する挙動も否定される

## PostgreSQLとの関係

`public.nvd_ra` には2026-08-25船橋1～12Rが12件存在していた。

- 全件 `data_sakusei_nengappi = 20260822`
- 全件同一 `xmin` で、同一トランザクションで投入・更新された形跡
- commit timestamp / SQL statement logging が無効のため正確な投入時刻は復元不能

Local Compass生成物が2026-08-24 20:23:09にこのDBデータを利用しているため、遅くともその時刻までにはDBへ取り込まれていた。

## Local Compassの読取経路

Local CompassはRA `.nvd` を直接読まず、PostgreSQLを参照している。

主な参照先:

```text
public.nvd_ra
public.nvd_se
```

そのため、UmaConn cache上で開催日名のRAファイルが見つからなくても、Local Compass生成自体には影響しなかった。

## local_odds_downloaderへの教訓

`get_race_schedule.ps1` 等でRAを探索するとき、次のような開催日固定のファイル名検索だけでは地方競馬で取りこぼす。

```text
RANV20260825*.nvd
```

今後のRA直接探索では、ファイル名の日付ではなく内部RAレコードを正として判定する。

推奨手順:

```text
直近数日分のRA*.nvdを候補化
        ↓
ZIP内部RAを読み取り
        ↓
内部の開催日・場コード・R番号で対象判定
        ↓
一致したレースの発走時刻等を採用
```

現在の設計:

```text
UmaConn RA優先
    ↓ 見つからない場合
PostgreSQL public.nvd_ra read-only fallback
```

は維持可能。

ただしUmaConn RA優先側は、将来的に「ファイル名の日付一致」から「内部RAレコード一致」へ改善する。

## 今後のルール

1. 地方RAのファイル名の日付を開催日と決め打ちしない。
2. `data_sakusei_nengappi` と開催日は別概念として扱う。
3. 対象レース判定は内部RAレコードの開催日・場コード・R番号を正とする。
4. RA直接探索で見つからない場合は、PostgreSQL `public.nvd_ra` をSELECTのみでフォールバック利用する。
5. 中央/JRA側のファイル配置感覚を地方データへそのまま当てはめない。

## 要点

> 地方競馬のRAは、後日開催分が数日前のRA配信ファイルへ先行収録されることがある。
>
> **ファイル名の日付ではなく、内部RAレコードの開催日を正として探索する。**
